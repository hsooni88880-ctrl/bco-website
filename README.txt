B.CO Firebase Hosting website

1) Put this folder in your B.CO project area or open a terminal here.
2) Make sure Firebase CLI is installed and you are logged in.
3) Run: firebase use YOUR_FIREBASE_PROJECT_ID
4) Run: firebase deploy --only hosting

Firebase will show the live URL, normally:
https://YOUR_PROJECT_ID.web.app

Pages:
https://YOUR_PROJECT_ID.web.app/privacy.html
